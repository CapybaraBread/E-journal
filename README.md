# E-journal

## Описание
Электронный журнал для школы, имеются страницы: оценок, главная, пользователи(только для админов).

## Как запустить
Для запуска требуется python версии 3.10.
После установки в терминале ввести по порядку:
```
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```
## Как получить админку
Зарегистрируйтесь на сайте.
После ввода команд в корне проекта будет файл db.sqlite3, это база данных, её нужно открыть и найти таблицу users_user в которой требуется поменять вашему пользователю роль на admin, готово
